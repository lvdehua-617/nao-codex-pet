# Nao · Codex Desktop Pet

An animated v2 desktop pet for the Codex desktop app, featuring nine standard animation states and sixteen clockwise look directions.

![Animation overview](previews/contact-sheet.png)

## Install

Run in PowerShell:

```powershell
.\install.ps1
```

The installer copies the package to `$CODEX_HOME/pets/nao`, or `$HOME/.codex/pets/nao` when `CODEX_HOME` is unset. Restart Codex and select **奈绪** from the pet picker.
